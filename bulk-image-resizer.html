    How to resize multiple images at once

    1. Select several photos, or drag them into the box.
    2. Choose Width in pixels, Percentage, or Target KB.
    3. Pick the format, such as JPG, and click Resize All.
    4. Download single files from the list, or use Download all as ZIP.

    Which mode should you use?

    • Width in pixels: every image gets the same width, and the height follows so nothing is stretched.
    • Percentage: every image is scaled by the same amount, such as 50 percent.
    • Target KB: every image is compressed to stay under the same file size, which suits forms and uploads.

    Tips for a large batch

    Phones have limited memory, so a batch of very large photos may be slow. If it stalls, process fewer images at a time. Everything stays on your device, and the list shows each file's old and new size so you can check the result.

    A simple way to prepare many photos

    Decide the output first: a width for a website, a percentage for a quick shrink, or a KB limit for forms. Run the batch, check one or two results by opening them, and then download the ZIP. If something looks wrong, change the setting and run the batch again from your original files.
