About this resize image by percentage tool

Use this page for scaling a picture up or down by a percentage, such as halving its width and height. Choose your photo, press Resize Image, and the finished file appears in seconds. Everything runs in your browser, so nothing is uploaded and no account is needed.

How to use

  1. Tap Select Image and choose a photo.

  3. Look at the size shown under the preview, then tap Download Image.

Tip

Work from the original photo. Shrinking is safe, but enlarging only stretches existing pixels.

FAQ

How do I resize an image by percentage?

Select your photo, open the Percentage tab, type a value such as 50, and click Resize Image. Width and height are scaled by the same percentage, so the shape stays the same.

What does resizing to 50 percent do?

It halves the width and height, so a 4000 × 3000 photo becomes 2000 × 1500. The file also gets much smaller, because it holds one quarter of the pixels.

Can I make an image bigger by percentage?

You can enter a value above 100, but enlarging adds no real detail, so the picture looks softer. Keep enlargements small.

When percentage is better than pixels

Use percentage when you simply want a smaller or larger version and do not care about an exact size. Use the pixels tool when a form or design fixes the width and height, and the KB tool when the limit is a file size.
