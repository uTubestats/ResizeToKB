How to Compress an Image to a Specific KB Size (Without Guessing)

Updated October 2026

You have a photo and a form that says the file must be under 100 KB. Most editors give you a quality slider, but a slider does not tell you the file size. This guide shows how to reach a specific size on purpose instead of by trial and error.

Why a quality slider is not enough

File size depends on several things at once: the pixel dimensions, how much detail and noise the picture contains, and the format. The same slider setting can give 80 KB for one photo and 400 KB for another. That is why "quality 70" is not a reliable way to reach a target.

A method that works

  1. Write down the exact limit. Note whether it is a maximum, a minimum, or a range.
  2. Crop first. Removing empty background lets the file spend its bytes on the subject.
  3. Use JPG or WebP. Both can be tuned to a target. PNG is lossless, so quality cannot be lowered to hit a size.
  4. Let a target tool search for the quality. The tool tries different quality levels and keeps the highest one that still fits.
  5. Shrink the dimensions only if needed. If even a moderate quality is too big, reduce the pixel size a little, then search again.

What the tool does for you

On the reduce image size in KB page you type the limit and click once. It tests quality levels, and it only shrinks the picture when quality alone cannot reach the size. For common limits, use the pages for 20 KB, 50 KB, 100 KB, 150 KB, and 200 KB.

Doing it by hand

If you use an editor instead, export at about 80 percent quality and check the size. If it is too big, lower the quality by ten points and export again. If it is too small, raise it. Repeat until you are just under the limit. It works, but it is slower than a tool.

When the file is still too big

  • Crop tighter, because a smaller scene needs fewer bytes.
  • Start from the original instead of a copy that was already compressed.
  • Use a photo taken in even daylight. Dark, grainy photos need many more bytes.
  • Check whether the form accepts a slightly higher limit.

When the file is too small

If a portal rejects the file because it is under a minimum, see how to increase image size in KB.

Check the result

Zoom in to 100 percent. Faces should be recognisable and any text should still be readable. If not, ask whether you can use a higher limit, or retake the photo in better light.

Frequently asked questions

Is compressing the same as resizing?

Not exactly. Resizing changes the pixel dimensions, while compressing changes how the file stores those pixels. Reaching a KB target usually uses both.

Why is my compressed image still larger than the target?

The picture may have too much detail, or it may be a PNG. Crop it, switch to JPG, and try again from the original.

Which format gives the smallest file?

For photos, WebP and JPG are usually much smaller than PNG. Use JPG when a form does not state a format.
