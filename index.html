How to resize an image online

  1. Select your photo or drop it into the box.
  2. Pick Pixels, Percentage, or Target KB.
  3. Click Resize Image, then download the result.

Resize image to 100KB, 50KB or 20KB

Many websites and exam or job forms accept only small files. Choose the Target KB tab, enter the limit, and the tool lowers quality and dimensions step by step until the file fits. Use JPG or WebP for the smallest files.

Change image size in KB online

Most upload errors are about file size, not how the picture looks. There are three common situations, and each has its own tool here.

  • The dimensions are wrong. Use the pixel presets for Instagram, YouTube, WhatsApp, passport photos, and exam forms.

Resize by pixels or percentage

Pixels and percentage change how big the picture is on screen. Choose resize image by pixels when a form or design gives you exact numbers, or resize image by percentage when you just want a smaller or larger copy. The tool opens JPG, PNG, and WebP files and saves a JPG, PNG, or WebP.

For the sharpest result, shrink rather than enlarge, and always work from your original photo. If you are not sure which tool to use, read how to compress an image to a specific KB size or how to resize an image to exact pixel dimensions.

Frequently asked questions about resizing images

The basics

How do I resize an image online for free?

Select your photo, choose Pixels, Percentage, or Target KB, and click Resize Image. Download the result when it appears. There is no signup and no watermark.

What is the difference between resizing to pixels and resizing to KB?

Pixels set the width and height of the picture. KB sets the file size. A form may ask for either one or both, and this tool handles each.

Which image formats can I use?

You can open JPG, PNG, WebP, and GIF files (an animated GIF uses its first frame). You can save the result as JPG, PNG, or WebP.

Does it work on a phone?

Yes. Open the site in Chrome or Safari, pick a photo from your gallery, and tap Resize Image. No app is needed.

File size in KB

How do I resize an image to 100KB?

Open the Target KB tab, type 100, select your photo, and click Resize Image. The tool compresses the JPG to just under 100 KB. The same steps work for 10, 15, 20, 50, 150, and 200 KB.

Why is my image still bigger than the size I set?

Very detailed or noisy photos need more bytes, and PNG files cannot be compressed by lowering quality. Choose JPG, crop out extra background, and start again from the original photo.

My form says the file is too small. What should I do?

Some forms demand a minimum size. Use the increase image size in KB tool, which saves a high-quality JPG and, if needed, adds harmless padding so the file reaches your minimum.

Will resizing reduce image quality?

Making an image smaller keeps it sharp. Reducing the file size in KB uses compression, so choose a limit that is as high as the form allows to keep more detail.

How many KB are in 1 MB?

Windows and many file managers count 1 MB as 1,024 KB, while some phones and websites count 1,000 KB. If a form allows 1 MB, aim for a little under 1,000 KB to be safe.

Pixels, shape, and sizes for platforms

How do I resize an image to exact pixel dimensions?

Open the Pixels tab, type the width and height, and click Resize Image. Switch off Keep ratio only if both values must match exactly, and crop first so the picture is not stretched.

Can I resize an image by percentage?

Yes. Open the Percentage tab and type a value such as 50. Width and height are scaled together, so the shape stays the same, and 50 percent halves both.

What size should I use for Instagram, TikTok, and YouTube?

Instagram feed posts commonly use 1080 × 1350, Instagram Stories and TikTok use 1080 × 1920, and YouTube thumbnails use 1280 × 720. Each has its own preset page here.

Why does my resized picture have a different shape?

The target shape was different from your photo. Presets crop the picture to fit, while custom sizes with Keep ratio off will stretch it. Crop first if the shape matters.

Can I resize a passport or exam photo?

Yes. Use the passport, SSC, JEE, or IBPS pages, which set the pixel size and KB limit listed in recent guides. Rules change, so always confirm them in the official notice.
