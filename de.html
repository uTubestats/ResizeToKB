Mit ResizeToKB verkleinern Sie ein Bild auf 20 KB, 50 KB oder 100 KB, legen exakte Pixel fest oder skalieren in Prozent. Wählen Sie Ihr Foto, dann Pixel, Prozent oder Ziel-KB und klicken Sie auf Größe ändern. Der Dienst ist kostenlos, und Ihre Fotos bleiben auf Ihrem Gerät: Es wird nichts hochgeladen.

So ändern Sie die Bildgröße online

  1. Wählen Sie Ihr Foto oder legen Sie es im Feld ab.

Häufige Fragen

Wie verkleinere ich ein Bild auf 100 KB?

Öffnen Sie den Tab Ziel-KB, geben Sie 100 ein, wählen Sie das Foto und klicken Sie auf Größe ändern. Das Tool komprimiert das JPG knapp unter 100 KB.

Werden meine Fotos auf einen Server hochgeladen?

Nein. Alles läuft in Ihrem Browser, deshalb bleiben die Fotos auf Ihrem Gerät.

Verliere ich an Qualität?

Ein kleineres Bild bleibt scharf. Bei einer KB-Grenze wird komprimiert, wählen Sie daher eine so hohe Grenze, wie das Formular erlaubt.

Funktioniert das auf dem Handy?

Ja. Öffnen Sie die Seite in Chrome oder Safari, wählen Sie ein Foto aus der Galerie und klicken Sie auf Größe ändern. Eine App ist nicht nötig.
