FAQ

How do I resize an image to exact pixel dimensions?

Select your photo, type the width and height, switch off Keep ratio if you need both values exactly, and click Resize Image. If the new shape differs from the original, the picture will stretch, so crop first when needed.

What is the difference between pixels and DPI?

Pixels are the actual width and height of the image. DPI only matters for printing and does not change the pixel count. A 413 × 531 pixel photo prints at 35 × 45 mm at 300 DPI.

Is it better to resize down or up?

Resizing down keeps the picture sharp. Resizing up stretches existing pixels, so the image looks softer.

Keep ratio, explained

With Keep ratio on, changing the width updates the height automatically, so the picture is never stretched. Switch it off only when a form needs both numbers exactly. Crop the picture to the right shape first, otherwise faces will look wide or tall.
