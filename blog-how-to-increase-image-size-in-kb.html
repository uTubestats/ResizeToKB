How to Increase Image Size in KB (When a Form Says the File Is Too Small)

Updated October 2026

Almost every guide about file size tells you how to make a picture smaller. But some upload forms do the opposite: they reject a file because it is too small. If you have seen a message like "minimum file size 20 KB," this guide explains what is happening and how to fix it.

Three different kinds of size

People mix these up, and it causes most of the confusion.

  • File size is how much storage the file uses, measured in KB or MB.
  • Dimensions are the width and height in pixels.
  • Print size is the physical size in centimetres or inches when printed.

A form that says "minimum 20 KB" is talking about file size only. Making the picture larger on screen does not always change the KB, and raising the KB does not make the picture look bigger.

Why forms set a minimum size

Portals that collect thousands of photos and scanned signatures use a minimum to filter out blank uploads, very low quality scans, and files saved by mistake. A tiny file often means the image is empty or unreadable, so the system rejects it before a person ever sees it.

Five ways to increase file size in KB

  1. Save at higher JPG quality. The same picture saved at maximum quality is often several times larger than one saved at a low setting.
  2. Use the original, not a copy. If you compressed a photo earlier, go back to the first version.
  3. Rescan at a higher resolution. For signatures, many forms suggest around 200 DPI. A scan at a higher setting creates more data.
  4. Increase the dimensions moderately. Adding pixels adds KB, though it does not add real detail, so do not overdo it.
  5. Add padding data. The increase image size tool saves a high-quality JPG and, if the file is still too small, adds harmless padding inside it. The picture itself does not change.

Step by step with the tool

  1. Open the tool and select your photo or signature scan.
  2. Type the minimum size from your form, for example 50.
  3. Tap Increase Size and check the result size under the preview.
  4. Download the JPG and upload it to the form.

What does not work

  • Renaming the file or changing its extension. The form checks the real file.
  • Enlarging a tiny image many times over. It gets blurry and may still fail the check.
  • Converting to a format the form does not accept.

A note on honesty

Use this only to meet a technical size rule with your own genuine photo or document. Do not alter what an official document shows. If you are unsure about a requirement, read the form's instructions or contact the organisation.

Frequently asked questions

Does increasing the file size improve the quality?

Not by itself. Padding makes the file larger without adding detail. Higher JPG quality or a better scan does improve the picture.

What if the form also has a maximum size?

Aim just above the minimum. For a range such as 20 to 50 KB, ask for about 25 KB. If your file is too large, use the reduce image size in KB tool.

Can I increase a PNG?

The tool outputs JPG, which most forms ask for. If a form requires PNG, check its instructions first.
